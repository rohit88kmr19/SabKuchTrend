## 🎯 Quick Reference

### File Locations
- Components: `src/components/`
- Pages: `src/pages/`
- API: `src/services/api.js`
- State: `src/context/CartContext.jsx`
- Utilities: `src/utils/helpers.js`
- Styles: `src/index.css`

### Common Tasks
- Add component → Create in `src/components/`
- Add page → Create in `src/pages/` + add route in `App.jsx`
- Add API call → Add function in `src/services/api.js`
- Add utility → Add function in `src/utils/helpers.js`
- Add style → Use Tailwind classes or add to `src/index.css`
